# 《今天也不想上班》 - Action Roguelike V2.0 (全平台极致优化版)

职场题材轻量级 Canvas / JavaScript 动作肉鸽游戏。

## 🌟 V2.0 优化内容说明

1. **彻底修复突然卡死/崩溃 Bug**：
   - **防切后台卡死**：限制物理单帧最大步长 `dt = Math.min(dt, 0.05)`，解决手机切后台切回、来电导致 `dt` 爆炸引发的物理螺旋卡死。
   - **数学防除零崩溃**：重构 `safeNormalize`，杜绝实体坐标计算出现 `NaN` 导致的游戏循环崩溃。
   - **空间哈希网格 (Spatial Grid)**：将怪物与子弹的大规模碰撞判定从 $O(N^2)$ 降低至接近 $O(N)$，彻底消除同屏怪多时的严重掉帧。
   - **通用对象池 (Object Pool)**：伤害飘字、经验宝石、子弹全面池化，消除频繁垃圾回收 (GC) 导致的画面卡顿。
   - **同屏实体与音频保护**：限制同屏刷怪上限及离屏自动回收；Web Audio API 加入并发限流保护。

2. **手机端多维度 UI 与横竖屏适配**：
   - **横竖屏自适应**：全面支持横屏与竖屏自适应切换，卡片与 HUD 动态响应。
   - **动态视口与安全区**：采用 `100dvh` 以及 `env(safe-area-inset-*)`，适配刘海屏与曲面屏，彻底避免移动端地址栏收放造成的界面抖动。
   - **防误触手势拦截**：启用 `touch-action: none;` 和 `user-select: none;`，彻底禁用浏览器的双击缩放、下拉刷新等系统干扰手势。

3. **移动端双触控操作手感升级**：
   - **自适应动态虚拟摇杆**：屏幕左侧半屏任意位置按下即时呼出摇杆，松手自动隐藏。
   - **技能按键与 CD 遮罩**：右下角冲刺与大招按键带有实时倒计时与 CD 遮罩。
   - **全设备兼容**：同时支持 PC 键盘（WASD / 空格 / J / K）与手机触控。

## 🎮 操作指南

| 平台 | 移动 | 冲刺 (Dash) | 摸鱼风暴 (大招) | 暂停/恢复 |
| :--- | :--- | :--- | :--- | :--- |
| **手机端** | 屏幕左半区滑动虚拟摇杆 | 右下角【冲刺】按键 | 右下角【摸鱼风暴】按键 | 顶部暂停按钮 |
| **PC 电脑端** | W/A/S/D 或 方向键 | 空格 (Space) 或 J 键 | K 键 | Esc 键 |
