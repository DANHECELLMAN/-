# 《测试》人物系统 (V1.5 终极优化版)

## 1. 游戏定位与版本升级
- **核心类型**：俯视角职场动作肉鸽 + Build构筑 + Boss战 + 员工晋升系统 + 无尽模式
- **V1.5 全新终极优化升级特性**：
  1. 🎯 **全武器智能自动索敌**：彻底移除依赖方向键与瞄准的旧逻辑，全武器（键帽、电鞭、水杯、辞职信、空调、工学椅）接入敌人密集度热点聚类算法，自动锁定敌人最多、威胁最高的区域！
  2. 💥 **范围伤害 (AOE) 判定与特效重构**：
     - **旋转马克杯**：扩大为真实环形扫荡区域，附带咖啡水花飞溅与多目标同时绞杀；
     - **快充充电线**：拓宽为广角高压扇形雷暴裂隙 + 智能链式闪电弹跳，全屏电击；
     - **辞职信/水洼/声波**：扩大有效面积与视觉冲击力。
  3. 🔥 **全新无尽模式 (通宵加班)**：没有时间上限，怪物随时间无限狂暴递增成长，每 90 秒随机刷新全系列强力 Boss 轮番突袭！
  4. ⚔️ **两大全新武器 & 冰火超武共鸣**：
     - **人体工学椅**：诺手Q式 360° 大杀四方旋转横扫，外圈造成 170%~250% 巨额暴击伤害、强力击退并吸取摸鱼能量回复生命！
     - **空调·制冷模式**：极寒冷气喷射，将命中敌人**冻结 1.0 秒**（完全定身停止行动）并减速；
     - **空调·制热模式**：滚烫热风波，高额初始伤害并附加**持续灼烧热伤害 (DoT)**；
     - **中央空调·冰火两重天 (共鸣超武)**：同时获得冷热双模式即可激活！周期性在最密集敌群引爆大范围冷热对流核爆（范围爆炸攻击），碎冰双倍暴击并点燃全场！
  5. 🏢 **关卡逐级解锁与新 Boss 体系**：
     - 通关前置关卡自动解锁下一关，保存至本地存档；
     - 新增 Boss 1【刁难的客户】：释放“需求红线”封锁禁区、砸下“巨型合同公文柱”阻碍移动与弹道（可破坏地形）、“方案打回”引力黑洞；
     - 新增 Boss 2【骚扰电话】：植入“响铃分机”减速声波塔（可破坏）、“夺命连环call”追踪弹幕、地表电波撕裂与全屏 EMP 脉冲；
     - 关卡中加入随机强力 Boss 突袭。
  6. 📋 **全新员工晋升与属性研习系统**：
     - 双分类研习树：**【👤 角色个人属性】**（生命、移速、回血、抗压、拾取、暴击、悟性、薪资）与**【⚔️ 武器全局属性】**（武器伤害、攻速CD、范围AoE、弹速、击退、超武共鸣）；
     - 消耗金币/工资升级，支持随时一键 100% 全额重置退款。

## 2. 目录结构
```text
game_project/
├── index.html        # 游戏主入口 (Canvas + 防重叠HUD + 晋升系统/关卡选择/无尽模式)
├── README.md         # 项目架构与设计升级说明文档
├── css/
│   └── style.css     # 职场霓虹UI、触屏摇杆底座、升级网格卡片与响应式动效
└── js/
    ├── constants.js  # 4大角色、8大武器、15项技能、关卡/无尽模式与双分类研习配置表
    ├── audio.js      # Web Audio API 纯代码合成音效引擎 (含工学椅旋转、冰冻、灼烧、冰火核爆、Boss地形破坏)
    ├── entities.js   # 玩家实体、可破坏地形障碍物、全武器自动索敌、状态机(冰冻/灼烧)与全Boss类
    ├── director.js   # 刷怪导演系统 (支持标准关卡与无尽模式无限成长+周期随机Boss)
    ├── game.js       # 核心游戏引擎、热点聚类索敌、关卡解锁状态机、员工晋升与存档系统
    └── main.js       # 程序入口与全平台UI交互绑定
```

## 3. 运行方式
无需安装任何外部依赖：
1. **本地运行**：在目录下启动本地静态服务（如终端输入 `python3 -m http.server 8000`），浏览器访问 `http://localhost:8000` 即可畅玩。
2. **全平台适配**：完整支持 PC 键鼠与手机端虚拟触控摇杆，自适应横竖屏与各分辨率屏幕。
